# 🏦 Bank Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project analyzes banking data using **SQL Server** and **Power BI** to extract meaningful business insights and build an interactive dashboard.

The project covers data exploration, analysis, business questions, SQL querying, data relationships, and visualization.

---

## 🗄️ Database

**Database:** Czech Bank Database

The dataset contains information about:

- Clients
- Accounts
- Loans
- Transactions
- Cards
- Districts
- Orders
- Dispositions

---

## 🛠️ Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI Desktop
- DAX

---

## 🎯 Project Objectives

- Explore and understand the banking dataset
- Analyze clients and accounts
- Analyze loans and loan amounts
- Analyze transaction activity over time
- Compare banking activity across districts
- Identify the top districts by loan amount
- Create relationships between database tables
- Build an interactive Power BI dashboard
- Present business insights through data visualization

---

## 📈 Power BI Dashboard

The Power BI dashboard provides insights into:

- Clients by District
- Total Accounts by District
- Total Loans by Status
- Total Transactions by Year and Month
- Total Loan Amount by Year and Month
- Top 10 Clients by Total Loan Amount
